# Persona 2: Researcher / Strategist

## 🔬 Dr. Leo Chen
**Role:** Policy Researcher & UX Strategist  
**Organization:** Government agency + freelance consulting  
**Experience:** 8+ years in policy research and user experience  

### Context & Environment
- Works in policy research analyzing complex social systems
- Conducts UX research for government digital services
- Often analyzes qualitative insights to identify systemic causes
- Needs to present findings to policymakers and stakeholders
- Works with large datasets and complex interdependencies

### Goals & Objectives
- **Structure open-ended qualitative data into cause-effect trees**
  - Convert interview insights into logical frameworks
  - Identify root causes from user feedback
  - Map systemic issues and their interconnections
- **Explore "what-if" changes and simulate logical consequences**
  - Test policy interventions before implementation
  - Model how changes in one area affect others
  - Predict unintended consequences of decisions
- **Export diagrams and summaries for research decks**
  - Create visual reports for policymakers
  - Generate executive summaries from complex logic
  - Share findings with non-technical stakeholders

### Pain Points & Challenges
- **Text-only analysis tools hide structure**
  - Qualitative analysis software (NVivo, Atlas.ti) is text-focused
  - Hard to see logical connections between insights
  - Difficult to identify patterns across multiple data sources
- **System-mapping software is too heavyweight for early exploration**
  - Tools like Kumu or Gephi are overkill for initial analysis
  - Steep learning curve for quick exploration
  - Too complex for sharing with stakeholders
- **No lightweight tool for logic exploration**
  - Need something between sticky notes and full system modeling
  - Want to sketch logic quickly and refine iteratively
  - Need to export results for further analysis

### Current Tools & Workarounds
- **NVivo/Atlas.ti**: For qualitative coding, but not for logic mapping
- **Miro/Mural**: For collaborative mapping, but not AI-assisted
- **PowerPoint**: For presentations, but not for logic exploration
- **Excel**: For data analysis, but not for causal reasoning

### How PromptBoard Helps
- **Lets researcher sketch logic quickly**
  - Input: "Users report confusion about eligibility criteria"
  - Output: Logic tree showing causes and effects
- **Keep the loop with AI for refinement**
  - AI suggests: "Add missing cause: unclear language"
  - AI suggests: "This effect might have multiple causes"
  - AI suggests: "Consider the reverse relationship"
- **Export lightweight JSON for later use**
  - Use in visualization tools (D3.js, Observable)
  - Import into data analysis software
  - Share with other researchers

### Success Metrics
- **Analysis speed**: Reduce time from 2 weeks to 3 days
- **Insight quality**: Identify 2+ additional causal relationships
- **Stakeholder engagement**: 80% understand the logic vs 40% with text
- **Export utility**: 90% of diagrams useful for further analysis

### Example Use Cases
1. **Policy Impact Analysis**: "If we change eligibility criteria, how does it affect application rates and processing time?"
2. **User Journey Mapping**: "If user encounters error X, what are the recovery paths and success rates?"
3. **Systemic Issue Analysis**: "What are the root causes of low digital adoption in rural areas?"
4. **Intervention Planning**: "If we provide training to caseworkers, what are the expected outcomes and risks?"

### Research Workflow
1. **Data Collection**: Interviews, surveys, observations
2. **Initial Coding**: Identify themes and patterns
3. **Logic Mapping**: Convert insights to cause-effect diagrams
4. **AI Refinement**: Get suggestions for completeness
5. **Export & Analysis**: Use JSON for further visualization
6. **Presentation**: Share visual logic with stakeholders

### Quote
> "I spend weeks analyzing qualitative data, but explaining the logic to policymakers is still a challenge. A tool that helps me structure insights into visual logic would be a game-changer for my research."
