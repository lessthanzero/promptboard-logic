# Persona 1: Product Manager

## 👩‍💼 Maya Patel
**Role:** Product Manager  
**Company:** Early-stage SaaS startup (15-50 employees)  
**Experience:** 3-5 years in product management  

### Context & Environment
- Works in a fast-paced startup environment with limited resources
- Uses Notion for documentation and Figma for design collaboration
- Struggles to communicate complex product decisions to non-technical stakeholders
- Often needs to justify roadmap priorities to executives and investors

### Goals & Objectives
- **Turn natural-language hypotheses into visual logic graphs**
  - Example: "If we raise prices, churn may rise, but revenue per user increases"
  - Need to show the trade-offs and dependencies clearly
- **Communicate reasoning behind product decisions**
  - Explain why certain features are prioritized
  - Show how one change affects multiple parts of the system
  - Make abstract concepts tangible for stakeholders
- **Iterate quickly with AI suggestions**
  - Get feedback on logic completeness
  - Identify missing edge cases or outcomes
  - Simplify complex decision trees

### Pain Points & Challenges
- **Whiteboards capture discussion but not reasoning**
  - Notes from meetings don't show the logical connections
  - Hard to reference later or share with remote team members
- **Difficult to track how one assumption affects multiple outcomes**
  - Price changes affect churn, revenue, support load, etc.
  - Current tools don't show these cascading effects
- **No lightweight tool between mind-maps and full systems modeling**
  - Mind maps are too simple for complex logic
  - Systems modeling tools (like Miro's system maps) are too heavyweight
  - Need something in between for product strategy

### Current Tools & Workarounds
- **Notion**: For documentation, but text-based logic is hard to follow
- **Figma**: For UI flows, but not for business logic
- **Whiteboards**: For brainstorming, but not persistent or shareable
- **Spreadsheets**: For data analysis, but not for logical reasoning

### How PromptBoard Helps
- **Turns text prompts into causal-logic diagrams**
  - Input: "If user skips onboarding, show tooltip, else proceed to dashboard"
  - Output: Visual flow with conditions, actions, and outcomes
- **Maintains bidirectional sync between diagram, text, and AI commentary**
  - Edit the diagram → text updates automatically
  - Edit the text → diagram updates automatically
  - AI suggests improvements as you work
- **Enables quick iteration and refinement**
  - AI suggests: "Add missing outcome for edge case X"
  - AI suggests: "Merge these similar branches"
  - AI suggests: "Simplify this complex condition"

### Success Metrics
- **Time to communicate complex decisions**: From 30 minutes to 5 minutes
- **Stakeholder understanding**: 90% can follow the logic vs 60% with text
- **Decision quality**: Catch 3+ edge cases before implementation
- **Team alignment**: Reduce follow-up questions by 50%

### Example Use Cases
1. **Pricing Strategy**: "If we increase price by 20%, what happens to churn, revenue, and support load?"
2. **Feature Rollout**: "If we release feature X to 10% of users, what are the success criteria and rollback conditions?"
3. **User Onboarding**: "If user completes profile setup, show dashboard; if they skip, show tooltips"
4. **A/B Testing**: "If variant A wins, implement globally; if variant B wins, iterate and retest"

### Quote
> "I need to show my CEO why we're prioritizing feature X over Y, but explaining the logic in text is painful. A visual logic board would make these conversations so much easier."
